# Feedback inbox — Bioregional Intelligence

Drop **feedback, corrections, directions, questions, or feature requests** here. You don't need to know how to develop the project — just describe what you'd like changed, and **Luiz processes the file periodically** (and may spawn agents to act on individual entries).

> **Audience:** anyone on the team (Andrea, Giulio, future contributors). If you'd rather develop the change yourself, see [`CONTRIBUTOR-ONBOARDING.md`](./CONTRIBUTOR-ONBOARDING.md) instead.

---

## How to use this file

1. **Open this file** in any markdown editor (VS Code, Obsidian, GitHub web UI — anything).
2. **Add an entry** under the right section using the template below.
3. **Save + commit + push** (or just push to GitHub web UI directly — no clone needed).
4. **Done.** No need to run anything locally. Luiz checks the file and processes entries; entries get marked `[done]` when shipped (with a link to the commit/PR).

If you don't want to commit yourself, just paste the entry into the ReFi BCN Telegram group with `[FEEDBACK]` at the top — Luiz will copy it in.

---

## Entry template

```markdown
### [theme/area] — short title
**From:** Andrea / Giulio / etc.
**Date:** YYYY-MM-DD
**Priority:** low / medium / high
**Status:** open

What you're noticing or asking for, in plain prose. Be specific where you can.

**If applicable — concrete details:**
- For data corrections: which project, what the current value is, what it should be.
- For visual feedback: which page (URL), what looks off, what you'd prefer.
- For features: what behavior you want, what you'd use it for.

**Open questions for Luiz / agent:**
- Anything you want clarified before this gets actioned.
```
