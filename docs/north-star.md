# Bioregional Intelligence — North Star

A long-horizon framing for what this dashboard is becoming.

## What this is

A Catalunya-scoped **bioregional intelligence layer**: maps and dashboards that make the ecosystem of regenerative actors, projects, and bioregional-health signals legible to a public audience. Inspired by:

- **`koala73/worldmonitor`** — territorial health-monitor archetype.
- **Dark Matter Labs `co-madrid`** — non-map analytical archetype.

We combine both, scoped to Catalunya as bioregion.

## Three current modes (V1)

1. **Cohort Maps** — public showcases of project cohorts (Regenerant Catalunya is the first; future cohorts follow). Editorial, narrative, screenshot-friendly.
2. **Actors** — the ecosystem-network view (ported from `refi-bcn-os/packages/maps/catalunya-actor-map/v0`). Internal-team-style ecosystem orientation.
3. **Indicators** — bioregional-health signals (in development; first indicator TBD).

## Future modes (BIS deepening, multi-month)

- Cohort feed (next cohorts beyond RC).
- Pulse strip — recent updates and events surfaced on `/`.
- Hermes/MCP hooks — query the dashboard from Telegram or another agent runtime.
- Notion/CRM sync — once the ReFi BCN CRM consolidation lands.
- Indicator deep-dives — river basins, forest cover, soil health, etc.

## Principles

- **Static-first.** No runtime database, no auth.
- **YAML-canonical for V1.** Notion-as-backend = future.
- **Editorial over analytical** for V1. Analytics dashboards (indicators) come later.
- **Public-readable and embed-friendly.** Every page should be linkable, screenshottable, fit for an external audience.
- **Continuity with the ReFi BCN visual identity.** Editorial-cartographic palette, dashed strokes, Fraunces + IBM Plex Mono.

## Out of scope

- Real-time collaborative editing.
- Visit analytics / tracking.
- Authentication / private data.
